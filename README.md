# 2D factory game

A learning project by me.

Currently aiming to replicate Mindustry/Factorio; will continue developing alone after that.

This project is NOT generated by AI. Though it is somewhat "AI-assisted" in code structure planning and corrections.
(I also don't like AI-Generated assets myself)

# Framework/Library

This project uses [Arcane](https://github.com/I-am-Yes/Arcane), a custom version of [libGDX](https://libgdx.com/).

# How to use
Just clone/download and open the project in JetBrains IntelliJ IDEA. (No additional steps required)
