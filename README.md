# 2D factory game

Currently aiming to replicate Mindustry/Factorio; will continue developing alone after that.

# Framework/Library

This project uses [Arcane](https://github.com/I-am-Yes/Arcane), a custom version of [libGDX](https://libgdx.com/).

# How to use
Just clone/download and open the project in JetBrain Intellij IDEA. (No additional steps required)
